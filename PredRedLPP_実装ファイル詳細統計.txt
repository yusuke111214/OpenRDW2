     $ git checkout -b backup/full-implementation

  └─ BatchFiles、CommandFiles、Experiment Results を削除
     $ git rm -r BatchFiles CommandFiles "Experiment Results" TrackingSpaces
     $ git rm _computed_stats.csv _computed_stats_v2.csv

ステップ3: 開発環境ファイルの削除
  └─ .claude、.idea を削除（.gitignoreに追加）
     $ git rm -r .claude .idea

ステップ4: 可視化機能の削除
  └─ GlobalConfiguration.cs で enablePotentialFieldVisualization = false

ステップ5: 実験用ドキュメントの削除」
