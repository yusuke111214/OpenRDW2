【矛盾点5】2段階選択プロセスの明示性
====================================================================
■論文記載:
論文では、予測的リダイレクションの概念説明（セクション2.4）において:
「1. 単一の経路T_predを予測する
 2. T_predは,複数のリダイレクション技術と異なるゲインからなるアクションセットUに基づいてリダイレクトされ,T_redが得られる
 3. T_redのコストベース分析を使用して,最良のリダイレクションπ_optimal ∈ Uを特定する」

と記載されているが、具体的な実装アルゴリズムとして「複数の軌跡から最良の1つを選択してから、その軌跡に対してアクションを評価する」という2段階プロセスは明示されていない。

■実装（PredRedLPP_Redirector.cs:249-280行目）:
```
// Step 4.5: Path similarity measureで単一の最良軌跡T_predを選択（論文Section 3.2.2）
// 2段階選択プロセスの第1段階（予測）
// HMD履歴との類似度（MSE）を使って、最もユーザーの移動パターンに近い軌跡を選択
Trajectory T_pred = pathPredictor.SelectBestTrajectoryUsingSimilarityMeasure(
    feasibleTrajectories,
    positionHistory
);

// Step 6: T_predに各アクションを適用して評価（論文Section 3.3）
// 2段階選択プロセスの第2段階（アクション選択）
// 計算量削減：N_trajectories × N_actions → N_trajectories + N_actions
(RedirectionAction bestAction, Trajectory bestTrajectory) = trajectoryEvaluator.EvaluateActionsForSingleTrajectory(
    T_pred,
    actionSet,
    ...
);
```

実装では、TrajectoryEvaluator.csに2つのメソッドが存在:
1. EvaluateAllActions: 全ての軌跡×全てのアクションを評価（論文の記載に近い）
2. EvaluateActionsForSingleTrajectory: 単一軌跡のみを評価（実際に使用されている）

■矛盾内容:
- 論文: 全ての組み合わせを評価すると読める（N_trajectories × N_actions）
- 実装: 最良軌跡を先に選択してから評価（N_trajectories + N_actions）
- 計算量: 実装の方が約7倍高速（11軌跡×19アクション=209回 vs 11回+19回=30回）

■影響度: 高
アルゴリズムの本質的な違い。ただし、実装のコメントでは「論文Section 3.2.2」を参照しており、論文の意図を正しく解釈している可能性もある。

【矛盾点10】Path similarity measureにおける割引方向
====================================================================
■論文記載（セクション2.3.1, 式2.5）:
「S = ∑_(i=1)^N▒a^i × ||p_(pred,i) - p_(hmd,i)||²」

ここで、iは1からNまで増加するため、式を字面通りに解釈すると:
- i=1: α^1 = 0.8
- i=2: α^2 = 0.64
- i=N: α^N = 0.8^N

つまり、iが大きいほど（後の点ほど）割引が大きくなる。

しかし、論文の文章では:
「単純な平均二乗誤差enhanced by a discount factor」
「これにより,より最近のバッファ状態により強い重みを提供しながら,高速な計算が保証される.」

と記載されており、「最近の状態により強い重み」を提供すると明示している。

■実装（Trajectory.cs:276-282行目）:
```
// 割引係数：新しい履歴ほど重要
// i=0（最古）→ discount^(N-1)
// i=N-1（最新）→ discount^0 = 1.0
int reverseIndex = historyArray.Length - 1 - i;
float weight = Mathf.Pow(discountFactor, reverseIndex);
```

■矛盾内容:
- 論文の式: i=1が最初でα^1、i=Nが最後でα^N → 後ほど小さい重み
- 論文の文章: 「最近のバッファ状態により強い重み」
- 実装: 最新がα^0=1.0、最古がα^(N-1) → 新しいほど大きい重み

論文の式と文章が矛盾しており、実装は文章の意図に従っている。

■影響度: 中
論文の式の解釈の問題。実装が論文の意図を正しく実装している可能性が高い。
